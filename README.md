## 📖 Overview
<a id="overview"></a>
HDDScan is an advanced software tool designed for disk analysis, available as a **complete free version** with all features and updates included. It allows users to diagnose problems and errors in various data storage units, including hard drives, RAID volumes, SSDs, and removable storage devices like USB flash drives.

With HDDScan, you can perform extensive reading, writing, and access tests to detect faulty sectors and ensure your drives are functioning optimally. The software displays SMART data, including temperature and factory settings, providing users with vital information about their drives' health.

## ⚡ Key Features
<a id="key-features"></a>
### Core Functionality
- Conduct reading, writing, and access tests on disks.
- Analyze SMART data for temperature and health monitoring.
- Perform verification tests in linear and "Butterfly" modes.
- Generate detailed reports in MHT format.
- Modify AAM, APM, and PM parameters for each volume.

### Advanced Features
- Compatibility with IDE (ATA), SATA HD, SCSI (SAS) HDD, and more.
- Temperature monitoring system for proactive maintenance.
- User-friendly interface for easy navigation and diagnostics.
